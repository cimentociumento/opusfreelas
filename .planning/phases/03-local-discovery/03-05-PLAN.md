# Plan: 03-05 — Mobile Provider Profile Setup

## Goal
Allow providers to configure their profile so they can be discovered.

## Context
- Discovery depends on providers having categories and location set.
- Need a simple UI for providers to update these fields.

## Proposed Changes

### 1. New Screen: `apps/mobile/app/(app)/profile/provider-setup.tsx`
- **Location Picker:** Simple button to "Usar minha localização atual".
- **Category Picker:** Multi-select list of service categories.
- **Save Button:** Calls `identity.updateProviderProfile`.

### 2. Integration
- Link this screen from the Home screen if the user is a provider.

## Verification
- [ ] Update profile as a provider and verify changes in database.
- [ ] Ensure the provider now appears in discovery results for the selected category and radius.
