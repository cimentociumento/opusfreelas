# Plan: 03-04 — Mobile Discovery UI

## Goal
Implement the provider discovery screen for contractors.

## Context
- elderly-friendly interface.
- Category grid for selection.
- Result list with large elements.

## Proposed Changes

### 1. New Screen: `apps/mobile/app/(app)/discovery/index.tsx`
- **Category Grid:** 2 or 3 columns with large icons and text.
- **Header:** "O que você precisa hoje?"
- **Filter Bar:** Simple radius selector (10km, 20km, 50km).

### 2. New Screen: `apps/mobile/app/(app)/discovery/results.tsx`
- Receives category and location via params.
- Fetches providers via `discovery.searchProviders`.
- Displays list of cards:
  - Provider name (initial/masked for now).
  - Categories offered.
  - Distance (e.g., "A 5km de você").
  - "Ver Perfil" button (large).

### 3. Navigation Update
- Add Discovery link to Home screen.

## Verification
- [ ] Navigate through categories and see results list.
- [ ] Verify that selecting a category updates the search results.
