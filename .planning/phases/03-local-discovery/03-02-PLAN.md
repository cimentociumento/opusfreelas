# Plan: 03-02 — Shared Discovery Schemas

## Goal
Define shared Zod schemas for discovery and service categories.

## Context
- Need a consistent set of service categories.
- Need schemas for search input and provider result list.

## Proposed Changes

### 1. New File: `packages/shared/src/discovery/schemas.ts`
- Define `serviceCategories` array (Roçada, Diarista, etc).
- Define `serviceCategorySchema` as a Zod enum.
- Define `providerSearchSchema`:
  - `latitude`: number
  - `longitude`: number
  - `category`: optional enum
  - `radius`: number (default 50)
- Define `providerResultSchema`:
  - `id`: string
  - `categories`: array of categories
  - `distance`: number (meters)

### 2. Export in `packages/shared/src/index.ts`
- Export everything from `./discovery/schemas.js`.
