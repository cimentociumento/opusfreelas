| T-04-02 | Elevation | Role flags tampered in JSON body | mitigate | Zod validation + DB truth + RLS; reject mismatched `userId` |
| T-04-03 | Information disclosure | Error leaks stack traces | mitigate | Central error handler returns generic message in production flag |
| T-04-04 | Denial of service | Log injection | mitigate | Structured logging without raw user-controlled strings as format |
