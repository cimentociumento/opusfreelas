# Plan: 02-04 — Demand Visibility & Spatial Queries

**Goal:** Implement the logic to filter demands based on geographical proximity and municipality.

**Requirements:** DEMD-03

**Context:**
- Uses PostGIS `ST_DWithin` for radius filtering.
- Visibility radius is stored per demand.

**Proposed Changes:**

1. **API Handlers:**
   - Update `apps/api/src/rpc/demands.ts` to include `demands.listVisible`:
     - Input: `lat`, `lng`, optional `municipality`.
     - Logic: Query demands where `ST_DWithin(location, ST_SetSRID(ST_MakePoint(lng, lat), 4326)::geography, visibility_radius * 1000)`.
     - Also filter by `status = 'aberta'`.

**Verification Plan:**

1. **Spatial Tests:**
   - Seed the database with demands at different locations (one in a specific city, another 50km away).
   - Test querying from a point near the first demand with a 10km radius (should find only the first).
   - Test querying with a 100km radius (should find both).
