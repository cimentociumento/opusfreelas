# Plan: 02-02 — Shared Demand Schemas

**Goal:** Define the data contracts for demands in the shared package to ensure consistency between API and Mobile.

**Requirements:** DEMD-01, DEMD-02

**Context:**
- `@amauc/shared` currently contains identity schemas.
- We need Zod schemas for creating, updating, and listing demands.

**Proposed Changes:**

1. **Shared Package:**
   - Edit `packages/shared/src/index.ts` to export new schemas.
   - Create `packages/shared/src/demands/schemas.ts`:
     - `demandStatusSchema`: Zod enum for `aberta`, `em_contato`, `encerrada`.
     - `demandUrgencySchema`: Zod enum for `baixa`, `media`, `alta`, `urgente_hoje`.
     - `createDemandSchema`: Validation for creating a demand (description length, coordinates, etc.).
     - `updateDemandSchema`: Partial validation for updates.
     - `demandResponseSchema`: Schema for the demand object returned by the API.

**Verification Plan:**

1. **Unit Tests:**
   - Add tests in `packages/shared` (if a test suite exists) or verify via a script.
   - Test `createDemandSchema` with valid and invalid inputs (e.g., short description, out-of-range coordinates).
