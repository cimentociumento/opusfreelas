# Plan: 02-05 — Mobile Demand Publishing UI

**Goal:** Provide a user-friendly interface for contractors to publish new service demands.

**Requirements:** DEMD-01

**Context:**
- Expo SDK 55.
- Uses `expo-router`.
- Needs to capture location (latitude, longitude, municipality).

**Proposed Changes:**

1. **New Screens:**
   - Create `apps/mobile/app/(app)/demands/create.tsx`.
   - Implement form with:
     - Service type (picker/select).
     - Description (multiline text input).
     - Urgency (segmented control or radio).
     - Visibility radius (slider).
     - Location picker (simple button to "Use current location" + manual municipality field for now).
2. **Logic:**
   - Use `expo-location` to get current coordinates.
   - Call `demands.create` RPC procedure.
   - Redirect to demand list or success screen.

**Verification Plan:**

1. **UI Walkthrough:**
   - Open the "Create Demand" screen in the app.
   - Fill all fields and submit.
   - Verify that the RPC call is made with correct data.
   - Verify success message and redirection.
