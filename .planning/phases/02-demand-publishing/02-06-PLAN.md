# Plan: 02-06 — Mobile Demand Management UI

**Goal:** Allow contractors to view, edit, and close their active demands.

**Requirements:** DEMD-02

**Context:**
- Needs a list view and a detail/edit view.

**Proposed Changes:**

1. **New Screens:**
   - Create `apps/mobile/app/(app)/demands/index.tsx` (My Demands list).
   - Create `apps/mobile/app/(app)/demands/[id].tsx` (Demand details/edit).
2. **Logic:**
   - Fetch "My Demands" using `demands.listMyDemands`.
   - Implement "Close Demand" action using `demands.close`.
   - Implement "Edit Demand" form (reusing parts of create form).

**Verification Plan:**

1. **Management Flow:**
   - View the list of demands.
   - Select a demand to see details.
   - Edit the description and save.
   - Close the demand and verify the status change in the UI.
